# crazy-random-design
A design portfolio by Tatiana Egoshina.

## Расстановка работ

На Mac открой в Finder файл **Расставить работы.command** и оставь окно Terminal открытым. Редактор откроется в браузере. Перетаскивай работы и меняй их ширину за синий угол. Чтобы перенести работу далеко, выбери её, прокрути до нужного места и нажми **Перенести сюда**.

Черновик сохраняется в этом браузере. **Опубликовать** отправляет десктопную раскладку в GitHub Pages. На экранах уже 900 CSS-пикселей работы по-прежнему идут в одной колонке в порядке из `index.html`.

[Открыть лендинг](https://tatianaegoshina.github.io/crazy-random-design/)
