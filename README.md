# crazy-random-design
A design portfolio by Tatiana Egoshina.

## Расстановка работ

На Mac открой в Finder файл **Расставить работы.command** и оставь окно Terminal открытым. Редактор откроется в браузере. Кликни по работе, чтобы выбрать её. Перетаскивай работу мышью, меняй её ширину кнопками **−** и **+** или за синий угол. Чтобы перенести работу далеко, выбери её, прокрути до нужного места и нажми **Перенести сюда**.

Черновик сохраняется в этом браузере. **Опубликовать** отправляет десктопную раскладку в GitHub Pages. На экранах уже 900 CSS-пикселей работы по-прежнему идут в одной колонке в порядке из `index.html`.

Кликай по работам с зажатой **Shift** или **⌘**, чтобы выбрать несколько. Перетащи любую из выделенных работ или нажми **−** и **+**, чтобы переместить или масштабировать всю группу. Клик по пустому месту снимает выделение.

Кнопка **Удалить** убирает выделенные работы из черновика. **Отменить** возвращает их. После публикации они исчезают из галереи на компьютере и телефоне. Исходники остаются в папке `artworks`.
